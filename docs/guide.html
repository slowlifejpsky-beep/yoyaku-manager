ききがきメモ

押すだけで録音し、話の内容を録音しながら文字起こし・要約して画面に出すAndroidアプリです。

できること

録音赤い「録音」ボタンを押すとすぐ始まります。画面を消しても、他のアプリを使っていても止まりません。通知の「停止して保存」からも止められます。
音声の保存端末内に audio.aac として保存します(1時間で約14MB)。3秒ごとにディスクへ書き出すので、途中でアプリが落ちても直前までは残ります。
リアルタイム要約録音中、音声をGeminiのLive APIへ流し続け、話すそばから文字起こしを表示します。要約(要点・決定事項・TODO)は約30秒ごとに更新します。Live APIにつながらないときは、約10秒ごとにまとめて文字起こしする方式に自動で切り替わります。電波が切れた間の分は、つながったときにまとめて処理します。
Googleドライブ保存録音を止めると「ききがきメモ」フォルダに、音声ファイルと要約ドキュメント(Googleドキュメント)を自動で保存します。下の「ドライブ連携の準備」が必要です。
共有ボタン記録の画面右上から、音声とテキストを共有メニューでドライブやNotebookLMアプリに渡せます。こちらは準備なしで使えます。

1. スマホに入れる

  1. スマホのブラウザでGitHubにログインし、このリポジトリの「Actions」タブを開きます。
  2. いちばん上の「Build APK」の実行結果を開き、下の「Artifacts」にある kikigaki-memo-apk をダウンロードします。
  3. ダウンロードしたzipを開き、中の kikigaki-memo.apk をタップしてインストールします。「提供元不明のアプリ」の許可を聞かれたら許可してください。

2. Gemini APIキーを入れる(要約に必要)

  1. aistudio.google.com を開き、「Get API key」からキーを作ってコピーします。
  2. アプリ右上の歯車 →「Gemini APIキー」に貼り付けます。

キーを入れなくても録音と音声の保存はできます。あとからキーを入れて、記録の画面の「まだ処理していない音声を文字起こし・要約する」を押せば要約を作れます。

3. ドライブ連携の準備(自動保存を使う場合だけ)

Googleの決まりで、アプリがドライブに書き込むには「このアプリは自分のものです」という登録が一度だけ必要です。パソコンのブラウザで行うのが楽です。

  1. console.cloud.google.com を開き、新しいプロジェクトを作ります(名前は何でも構いません)。
  2. 「APIとサービス」→「ライブラリ」で Google Drive API を探して「有効にする」を押します。
  3. 「OAuth同意画面」(Google Auth Platform)を設定します。対象は「外部」を選び、「テストユーザー」に自分のGoogleアカウントを追加します。
  4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類は Android を選び、下の2つを入力して作成します。
パッケージ名app.kikigaki.memo
SHA-1E3:89:C4:6D:4E:29:E3:4B:87:00:0E:EE:90:51:C6:8B:75:73:8E:5F

同じ値はアプリの設定画面のいちばん下にも表示されます。

  1. アプリの設定で「Googleドライブと連携する」を押し、アカウントを選んで許可します。

アプリが触れるのは、このアプリ自身が作ったファイルだけです(ドライブの他のファイルは見えません)。同意画面が「テスト」のままだと、7日ほどで許可が切れて再連携を求められることがあります。気になる場合は同意画面を「本番環境」に切り替えてください。

知っておくとよいこと

  • 音声はGemini(Google)に送られます。お客様との会話など、録音してよい場面かどうかは事前に確認してください。
  • Geminiの無料枠には1日あたりの回数上限があります。長時間の録音が多い場合は有料枠を検討してください。
  • 電話の着信など、他のアプリがマイクを使うと、その間の音声は録れないことがあります。
  • 記録を削除すると端末内の音声も消えます。ドライブに保存済みのファイルは残ります。
